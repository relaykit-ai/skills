# RelayKit skills

The RelayKit skill teaches an AI coding tool — Claude Code, Cursor, Codex, Copilot, Windsurf, Cline and others — to send text messages from an application through RelayKit: how to send by name, the pitfalls, and how to check that a text landed.

Install it either way; they are the same bytes:

```
npx skills add relaykit-ai/skills
npx skills add https://relaykit.ai
```

`skills/relaykit/SKILL.md` is a mirror of https://relaykit.ai/.well-known/agent-skills/relaykit/SKILL.md, refreshed by a workflow that verifies the published digest before committing. It is never edited here — the source is generated on relaykit.ai from the message library.

Readable copies: https://relaykit.ai/AGENTS.md · the API reference https://relaykit.ai/docs/v1.md · the catalog https://relaykit.ai/corpus.json
